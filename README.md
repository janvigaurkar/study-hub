# 📚 Study Hub

A modern and responsive **Student Learning Platform** built using **HTML, CSS, Bootstrap, and JavaScript**. Study Hub helps students improve productivity by providing useful study tools, notes, quizzes, and a clean user-friendly interface.

---

## 🚀 Features

- 🎨 Modern Responsive UI
- 🌙 Dark & Light Mode
- 📖 Study Notes Section
- ❓ Interactive Quiz
- ⏰ Pomodoro Timer
- ✅ To-Do List
- 📝 Notes Manager
- 📅 Study Planner
- 📊 Progress Tracking
- 🔍 Search Functionality
- 📱 Mobile Friendly Design
- ✨ Smooth Animations
- 💾 Local Storage Support

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)

```bash

```

### Open Project

```bash
cd study-hub
```

Open **index.html** in your browser.
